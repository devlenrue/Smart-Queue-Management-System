SmartQueue API

Smart Queue Management System — REST API, version 1.

Status

  • /api/v1/system/health — service and database health

Public endpoints

  • GET /api/v1/services — the service catalogue with live queue figures
  • GET /api/v1/services/:id/queue — today's queue for one service
  • GET /api/v1/queues — every queue for a given date

Getting a token

  • POST /api/v1/auth/register
  • POST /api/v1/auth/login — returns a bearer token
  • Send it as Authorization: Bearer <token>
The mobile client is a separate Flutter application. See docs/api.md for the full reference.
